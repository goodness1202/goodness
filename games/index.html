Games that learn like a brain

Each game trains its own small neural network from dopamine alone. Hits play a calm beat and raise dopamine; misses play noise and drop it. The network adjusts its synapses so calm beats repeat and noise fades — the same idea as cortical cells in a dish learning to play Pong. Pong is level 1 (easiest); every level after it is harder.

How the "brain" works

Every game runs a tiny multi-layer perceptron (a few hundred synapses) with Q-learning and experience replay. Each frame it picks an action (epsilon-greedy exploration), receives a dopamine reward, and updates its weights so actions followed by a calm beat are repeated and actions followed by noise are suppressed. A moving neuron dish draws the activity: calm ripples spread on hits, erratic static flashes on misses.

  • Hit → calm beat (+reward) → dopamine rises → ripples in the dish
  • Miss → noise burst (−reward) → dopamine falls → static flashes in the dish
  • Epsilon starts at 1.0 (random babbling) and decays as the brain figures the game out
