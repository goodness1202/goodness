Everything a 2D game needs, nothing it doesn't

The depth of a real engine — physics, tweens, particles, tilemaps, a synth — behind APIs you can learn in an afternoon.

🌳

Node & scene system

Godot-style trees with instancing, groups, signals and a searchable class registry. Compose, don't inherit.

🎨

Visual editor

Scene dock, inspector, viewport with gizmos, play mode, script editor with live compile checks, console — in your browser.

🏃

Arcade physics

CharacterBody2D with move_and_slide + coyote time, rigid bodies with bounce, one-way platforms, areas, raycasts.

🧩

Tilemap levels

Draw entire levels as strings of characters. Solid tiles collide automatically. The friendliest level format around.

✨

Effects & juice

Tweens with 16 easings, a full particle system, screen shake, squash & stretch — plus a WebAudio synth: sound with zero files.

🖼

Procedural art library

30+ built-in textures (hero, slime, ship, coin, torch…) — build and ship complete games without downloading a single asset.

🎞️

Keyframe animation

AnimationPlayer with property, colour and method-call tracks, easing, loops and queues — or one-line tweens for the quick wins.

🧭

Pathfinding enemies

NavigationRegion2D bakes your tilemap into a nav grid; NavigationAgent2D walks bodies along it. Add RayCast2D eyes and the hunt is on.

🏔️

Depth without work

Parallax backgrounds with one-image endless horizons, y-sorted top-down depth, canvas layers for HUDs.

💡

Light & mood

CanvasModulate for night and weather, PointLight2D torches that flicker and pulse — atmosphere without shaders.

🌐

Free APIs built in

PokéAPI, Open Trivia DB, Open-Meteo, the Art Institute of Chicago and Datamuse — free, no keys — with caching, timeouts and offline fallbacks.

💾

Publish anywhere

A project is one JSON file. Run it from the repo, bundle it to a single .js + html, or drop it on any static host.

📚

Taught, not just documented

Interactive in-editor lessons that watch your moves and auto-advance, a runnable-snippet API panel, and a 13-chapter docs book.

The internet is your content pipeline

The engine ships with first-class wrappers for five complete, free, key-less public APIs — and an in-editor training panel that teaches you to use them with live, runnable snippets and ten graded tasks.
